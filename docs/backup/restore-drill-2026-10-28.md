## 五、這次演練沒有涵蓋的部分

真的要切換到新的 Supabase 專案時，還需要做這些（步驟見 `scripts/backup/README.md`），這次沒有實際操作：

1. 在新專案的 Authentication → Third-Party Auth 加入 Firebase 專案（Google 登入）。
2. 重新部署 Edge Functions（admin-users、ocr-receipt）並設定 Secrets。
3. 網頁改用新專案的網址與 publishable key，重新部署。
